# Mini Message Board

A simple forum/message app named Message Aegis.

Deployment 🔗 https://mini-message-board-production-c68a.up.railway.app/

The project features a simple node express server with routes to view all messages, view details of one message, or create a new message.

Note: Message creation route located at '/new'.

Main skills practiced:

- NodeJS servers
- Express framework routing
- EJS templating language
- Deployment via PaaS
